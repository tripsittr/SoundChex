FFmpeg  (full GPL build — ffmpeg + ffprobe)
    License: GPL (GNU General Public License), version 3.
    https://www.ffmpeg.org/legal.html
    This bundle ships a FULL FFmpeg build configured with --enable-gpl,
    including libx264 and libmp3lame. GPL-3.0 is compatible with SoundChex's
    AGPL-3.0-or-later license. Corresponding source for FFmpeg is available from
    https://www.ffmpeg.org/download.html and its git repository.
    Bundled codec/library components and their licenses:
      - libx264           GPL-2.0-or-later (H.264 software encoder)
      - libmp3lame (LAME) LGPL-2.1-or-later (MP3 encoder)
      - FFmpeg's own code GPL-3.0 (with --enable-gpl)
    macOS builds: ffmpeg.martin-riedl.de (static, per-arch).
    Linux/Windows builds: github.com/BtbN/FFmpeg-Builds (static, GPL).

    NOTE ON PATENTS: H.264 (AVC) is covered by patents separate from copyright.
    SoundChex is free to end users and the encoding is performed by the user on
    their own media (the VLC/Handbrake posture); see BundledServer.md for the
    project's reasoning. This notice concerns copyright licenses only.

-------------------------------------------------------------------------------
Tailwind CSS CLI  (standalone binary — plugin stylesheet compilation)
    License: MIT
    https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE
    Used to compile a plugin's stylesheet when that plugin is enabled, so a
    plugin author can write ordinary Tailwind classes. This is the same Tailwind
    CSS that the web interface is built with, shipped as a self-contained
    executable so no Node.js toolchain is required on the user's machine.
    Embedded components and their licenses:
      - Bun               MIT (the JavaScript runtime the binary is built on)
      - JavaScriptCore /  LGPL-2.1-or-later (the JS engine inside Bun)
        WebKit            https://webkit.org/licensing-webkit/
    Corresponding source: Tailwind CSS from the repository above; Bun from
    https://github.com/oven-sh/bun; WebKit/JavaScriptCore from
    https://webkit.org/getting-the-code/. The binary is redistributed unmodified
    from the upstream release, and may be replaced by the user with another
    build of the same version.
