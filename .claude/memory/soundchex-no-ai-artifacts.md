Anything published reads as authored by the developer. No
`Co-Authored-By: Claude` trailers, no "Generated with Claude Code" lines, no
mention of AI or an LLM having been involved — in commit messages, PR titles
and bodies, issue comments, changelogs or documentation.

**Why:** the work is published under the developer's name, and a generation
notice in a commit message is a permanent part of the repository's history.

**How to apply:** write in a neutral voice throughout. The default instructions
add these trailers unless told otherwise, so it is an active omission rather
than a passive one — check a commit message before it lands rather than after.

Recovered on 22 August 2026 from an orphaned memory directory belonging to a
project path that no longer exists. It had been in effect all along; it was
simply not written anywhere that would survive.
